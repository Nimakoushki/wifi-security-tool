                             معرفی پروژه

WiFi Security Tool Pro یک ابزار حرفه‌ای و کاربردی برای تست امنیت شبکه‌های 
وای‌فای است که با زبان پایتون و کتابخانه‌ی مدرن CustomTkinter طراحی و پیاده‌سازی
شده است. این ابزار با هدف آموزش مفاهیم امنیت شبکه و کمک به کاربران برای تست
امنیت شبکه‌های شخصی خود ساخته شده است.

رابط کاربری این ابزار کاملاً گرافیکی، مدرن و فارسی‌سازی شده است و کاربران
می‌توانند بدون نیاز به دانش فنی عمیق، از قابلیت‌های آن استفاده کنند.
این ابزار برای سیستم‌عامل ویندوز طراحی شده و به‌خوبی با آن سازگار است.

================================================================================
                          ✨ قابلیت‌های اصلی
================================================================================

1. اسکن شبکه‌های وای‌فای
   - نمایش تمام شبکه‌های وای‌فای موجود در محدوده
   - نمایش اطلاعات کامل هر شبکه شامل:
     * SSID (نام شبکه)
     * BSSID (آدرس MAC اکسس‌پوینت)
     * کانال استفاده‌شده
     * قدرت سیگنال به صورت درصد و نوار گرافیکی
     * نوع امنیت (WEP، WPA، WPA2، WPA3، Open)

2. گرفتن Handshake (هندشیک)
   - ضبط هندشیک شبکه‌های WPA/WPA2 (شبیه‌سازی شده برای ویندوز)
   - نمایش وضعیت عملیات به صورت لحظه‌ای
   - ذخیره فایل CAP برای استفاده در بخش کرک

3. شکستن رمز وای‌فای با حمله دیکشنری
   - استفاده از فایل‌های wordlist دلخواه کاربر
   - نمایش پیشرفت عملیات با نوار پیشرفت
   - نمایش رمز فعلی در حال تست
   - قابلیت توقف عملیات در هر زمان

4. بازیابی رمز از حافظه ویندوز
   - دریافت رمز شبکه‌های ذخیره‌شده در ویندوز
   - نمایش رمز به صورت واضح و قابل کپی
   - قابلیت کپی رمز در کلیپ‌بورد

5. تنظیمات پیشرفته
   - انتخاب اینترفیس شبکه پیش‌فرض
   - تعیین مسیر فایل دیکشنری پیش‌فرض
   - تنظیم پوشه ذخیره‌سازی لاگ‌ها
   - تنظیم تأخیر حمله Deauth
   - تنظیم حداکثر طول برای حمله Brute Force
   - ذخیره و بارگذاری خودکار تنظیمات

6. تم تاریک/روشن
   - تغییر یک‌کلیکی تم برنامه
   - حفظ تنظیمات تم در دفعات بعدی اجرا

7. تب درباره من
   - نمایش اطلاعات توسعه‌دهنده
   - لینک مستقیم به گیت‌هاب
   - تذکر اخلاقی

================================================================================
                        🛠 تکنولوژی‌های استفاده‌شده
================================================================================

1. Python 3.8+
   زبان اصلی برنامه‌نویسی با قابلیت‌های پیشرفته شی‌گرا

2. CustomTkinter
   کتابخانه‌ی مدرن برای ساخت رابط‌های کاربری زیبا و حرفه‌ای
   پشتیبانی از تم تاریک/روشن و ویجت‌های سفارشی

3. Windows WLAN API / Netsh
   تعامل با سرویس‌های شبکه ویندوز از طریق دستورات سیستمی
   اجرای دستورات netsh برای اسکن، اتصال و مدیریت شبکه

4. Multithreading (چندنخی)
   اجرای همزمان عملیات‌های سنگین بدون قفل کردن محیط گرافیکی
   بهبود تجربه کاربری و پاسخ‌دهی برنامه

5. JSON
   ذخیره و بارگذاری تنظیمات کاربر در فایل settings.json
   مدیریت آسان و خوانا برای کاربران پیشرفته

================================================================================
                      🚀 راهنمای کامل استفاده
================================================================================

📶 اسکن شبکه‌ها
------------------------------------------------------------
1. به تب Scan بروید
2. روی دکمه Start Scan کلیک کنید
3. منتظر بمانید تا شبکه‌های اطراف کشف شوند
4. شبکه‌های پیدا شده در جدول نمایش داده می‌شوند
5. روی هر شبکه کلیک کنید تا به عنوان هدف انتخاب شود
6. دکمه Select as Target را بزنید تا شبکه را به بخش‌های دیگر معرفی کنید

📡 گرفتن هندشیک
------------------------------------------------------------
1. به تب Handshake بروید
2. اطلاعات شبکه هدف را وارد کنید:
   - SSID: نام شبکه
   - BSSID: آدرس MAC (مثلاً 2C:30:33:14:5A:9F)
   - Channel: کانال شبکه (مثلاً 6)
3. روی دکمه Start Capture کلیک کنید
4. وضعیت عملیات را در لاگ مشاهده کنید
5. پس از اتمام، فایل CAP در مسیر مشخص شده ذخیره می‌شود

🔑 شکستن رمز با دیکشنری
------------------------------------------------------------
1. به تب Crack بروید
2. نام شبکه هدف (SSID) را در فیلد مربوطه وارد کنید
3. یک فایل دیکشنری انتخاب کنید:
   - روی Browse کلیک کنید
   - فایل txt شامل رمزهای احتمالی را انتخاب کنید
   - یا روی Create Sample Wordlist کلیک کنید
4. روی دکمه Start Dictionary Attack کلیک کنید
5. نوار پیشرفت را تماشا کنید
6. رمز پیدا شده در بخش Results نمایش داده می‌شود

💾 بازیابی رمز از حافظه ویندوز
------------------------------------------------------------
1. به تب Crack بروید
2. نام شبکه (SSID) را وارد کنید
3. روی دکمه Find from Windows Memory کلیک کنید
4. اگر رمز در ویندوز ذخیره شده باشد، نمایش داده می‌شود
5. می‌توانید رمز را کپی یا ذخیره کنید

⚙️ تنظیمات پیشرفته
------------------------------------------------------------
1. به تب Settings بروید
2. تنظیمات زیر را شخصی‌سازی کنید:
   - Default Interface: اینترفیس پیش‌فرض
   - Default Wordlist: مسیر فایل دیکشنری
   - Logs Folder: پوشه ذخیره لاگ‌ها
   - Deauth Delay: تأخیر بین پکت‌های Deauth
   - Max Brute Force Length: طول رمز در حمله Brute Force
3. روی Save Settings کلیک کنید

================================================================================
                      🧰 ساخت فایل اجرایی (exe)
================================================================================

برای ساخت یک فایل exe مستقل که بدون نیاز به پایتون اجرا شود:

مرحله 1: پیدا کردن مسیر customtkinter
------------------------------------------------------------
pip show customtkinter

نتیجه:
Name: customtkinter
Version: 6.0.0
Location: C:\Users\YourUser\AppData\Local\Python\pythoncore-3.14-64\Lib\site-packages

مسیر Location را کپی کنید.

مرحله 2: اجرای دستور打包
------------------------------------------------------------
python -m PyInstaller --onefile --windowed --add-data "مسیر_واقعی/customtkinter;customtkinter/" --hidden-import darkdetect --hidden-import packaging --hidden-import packaging.version main.py

مثال با مسیر واقعی:
python -m PyInstaller --onefile --windowed --add-data "C:/Users/AdibianStore/AppData/Local/Python/pythoncore-3.14-64/Lib/site-packages/customtkinter;customtkinter/" --hidden-import darkdetect --hidden-import packaging --hidden-import packaging.version main.py

مرحله 3: پیدا کردن فایل exe
------------------------------------------------------------
فایل main.exe در پوشه dist ساخته می‌شود:
C:\Users\YourUser\Desktop\wifi_cracker\dist\main.exe

مرحله 4: تست
------------------------------------------------------------
cd dist
main.exe

خطاهای رایج و راه‌حل‌ها:
------------------------------------------------------------
ERROR: Unable to find 'customtkinter'
→ راه‌حل: مسیر --add-data را با مسیر صحیح جایگزین کنید

'pyinstaller' is not recognized
→ راه‌حل: از python -m PyInstaller استفاده کنید

فایل exe اجرا نمی‌شود
→ راه‌حل: آنتی‌ویروس را موقتاً غیرفعال کنید یا فایل را به لیست استثناها اضافه کنید
