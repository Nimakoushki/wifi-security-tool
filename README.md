📌 معرفی پروژه
-----------------------------------------------------------------------

این یک ابزار حرفه‌ای برای تست امنیت شبکه‌های وای‌فای است که با زبان 
پایتون و کتابخانه‌ی CustomTkinter ساخته شده است. رابط کاربری مدرن، 
ساده و کاملاً فارسی‌سازی شده دارد و برای محیط ویندوز طراحی شده است.

هدف اصلی: آموزش مفاهیم امنیت شبکه و تست امنیت شبکه‌های شخصی.

-----------------------------------------------------------------------
✨ قابلیت‌های اصلی
-----------------------------------------------------------------------

✅ اسکن شبکه‌های وای‌فای اطراف (نمایش SSID، BSSID، کانال، قدرت سیگنال، نوع امنیت)
✅ گرفتن هندشیک WPA/WPA2 (شبیه‌سازی شده برای ویندوز)
✅ حمله دیکشنری برای شکستن رمز وای‌فای
✅ بازیابی رمزهای ذخیره‌شده در حافظه ویندوز
✅ تنظیمات پیشرفته (اینترفیس، مسیر دیکشنری، لاگ‌ها و...)
✅ تم تاریک/روشن با یک کلیک
✅ تب درباره من با اطلاعات توسعه‌دهنده و لینک گیت‌هاب

-----------------------------------------------------------------------
🛠 تکنولوژی‌های استفاده‌شده
-----------------------------------------------------------------------

- Python 3.8+
- CustomTkinter (رابط کاربری مدرن)
- Windows WLAN API / Netsh
- Multithreading (اجرای همزمان عملیات)
- JSON (ذخیره تنظیمات)

-----------------------------------------------------------------------
📦 نصب و راه‌اندازی
-----------------------------------------------------------------------

1. دریافت کد از گیت‌هاب:
   git clone https://github.com/Nimakoushki/wifi-security-tool.git
   cd wifi-security-tool

2. نصب کتابخانه‌های مورد نیاز:
   pip install customtkinter pyinstaller pillow darkdetect

3. اجرای برنامه:
   python main.py

-----------------------------------------------------------------------
🚀 راهنمای استفاده از بخش‌های مختلف
-----------------------------------------------------------------------

📶 اسکن شبکه:
   - به تب Scan بروید
   - روی Start Scan کلیک کنید
   - شبکه‌های پیدا شده را مشاهده کنید
   - با کلیک روی هر شبکه، آن را به عنوان هدف انتخاب کنید

📡 گرفتن هندشیک:
   - به تب Handshake بروید
   - اطلاعات شبکه هدف (SSID، BSSID، کانال) را وارد کنید
   - روی Start Capture کلیک کنید
   - منتظر ضبط هندشیک باشید

🔑 شکستن رمز:
   - به تب Crack بروید
   - نام شبکه (SSID) را وارد کنید
   - یک فایل دیکشنری انتخاب کنید
   - روی Start Dictionary Attack کلیک کنید
   - منتظر نتیجه باشید

💾 بازیابی از ویندوز:
   - در تب Crack، نام شبکه را وارد کنید
   - روی Find from Windows Memory کلیک کنید
   - در صورت وجود، رمز نمایش داده می‌شود

⚙️ تنظیمات:
   - به تب Settings بروید
   - تنظیمات دلخواه را اعمال کنید
   - روی Save Settings کلیک کنید

-----------------------------------------------------------------------
🧰 ساخت فایل اجرایی (exe) برای ویندوز
-----------------------------------------------------------------------

۱. مسیر کتابخانه customtkinter را پیدا کنید:
   pip show customtkinter

۲. دستور打包 را اجرا کنید (مسیر را جایگزین کنید):
   python -m PyInstaller --onefile --windowed --add-data "مسیر/customtkinter;customtkinter/" --hidden-import darkdetect --hidden-import packaging --hidden-import packaging.version main.py

۳. فایل main.exe در پوشه dist ساخته می‌شود.
