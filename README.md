                      🔒 WiFi Security Tool Pro
=======================================================================

یک ابزار حرفه‌ای برای تست امنیت شبکه‌های وای‌فای
ساخته شده با ❤️ توسط نیما کوشکی


📌 این برنامه چیه و به چه دردی می‌خوره؟

این برنامه به شما کمک میکنه شبکه‌های وای‌فای اطراف رو اسکن کنید،
هندشیک شبکه‌های امنیتی رو بگیرید، رمز وای‌فای رو با دیکشنری پیدا کنید
و رمزهای ذخیره شده در ویندوز رو بازیابی کنید.


🌟 قابلیت‌های جذاب برنامه

🔍 اسکن شبکه
   تمام شبکه‌های وای‌فای اطراف رو پیدا میکنه و قدرت سیگنال، کانال و نوع امنیت رو نشون میده.

📡 گرفتن هندشیک
   هندشیک شبکه‌های WPA/WPA2 رو ضبط میکنه (مناسب برای محیط‌های آموزشی).

🔑 شکستن رمز
   با حمله دیکشنری رمز شبکه رو پیدا میکنه و میتونید فایل دیکشنری خودتون رو بدید.

💾 بازیابی از ویندوز
   رمزهای ذخیره شده در ویندوز رو برمیگردونه.

⚙️ تنظیمات پیشرفته
   امکان شخصی‌سازی اینترفیس، مسیر دیکشنری و تنظیمات لاگ.

🌓 تم تاریک/روشن
   تغییر یک کلیکی تم برنامه.


🛠 تکنولوژی‌های استفاده شده

🐍 پایتون 3.8+
🎨 CustomTkinter برای رابط کاربری مدرن
🖥️ Windows WLAN API برای کار با شبکه
⚡ Multithreading برای اجرای همزمان
📁 JSON برای ذخیره تنظیمات


📦 چطور نصبش کنم؟

مرحله ۱: دریافت کد
git clone https://github.com/Nimakoushki/wifi-security-tool.git
cd wifi-security-tool

مرحله ۲: نصب کتابخانه‌ها
pip install customtkinter pyinstaller pillow darkdetect

مرحله ۳: اجرا
python main.py


🎯 راهنمای استفاده

📶 اسکن شبکه
   به تب Scan بروید و Start Scan را بزنید.

📡 گرفتن هندشیک
   به تب Handshake بروید و اطلاعات شبکه را وارد کنید.

🔑 شکستن رمز
   به تب Crack بروید، نام شبکه و فایل دیکشنری را انتخاب کنید.

💾 بازیابی از ویندوز
   در تب Crack، نام شبکه را وارد و Find from Windows Memory را بزنید.

⚙️ تنظیمات
   به تب Settings بروید و تنظیمات را شخصی‌سازی کنید.


🧰 ساخت فایل exe

۱. مسیر customtkinter را پیدا کنید:
   pip show customtkinter

۲. دستور打包 را اجرا کنید:
   python -m PyInstaller --onefile --windowed --add-data "مسیر/customtkinter;customtkinter/" --hidden-import darkdetect --hidden-import packaging --hidden-import packaging.version main.py

۳. فایل exe در پوشه dist ساخته میشود.
