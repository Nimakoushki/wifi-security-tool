=======================================================================
                      WiFi Security Tool Pro
=======================================================================

یک ابزار ساده و حرفه‌ای برای تست امنیت وای‌فای

توسعه‌دهنده: نیما کوشکی
نسخه: 2.0
زبان: پایتون

-----------------------------------------------------------------------
چیست؟
-----------------------------------------------------------------------

این برنامه به شما کمک می‌کند:
- شبکه‌های وای‌فای اطراف را ببینید
- هندشیک شبکه‌های امنیتی را بگیرید
- رمز وای‌فای را با دیکشنری پیدا کنید
- رمزهای ذخیره‌شده در ویندوز را بازیابی کنید

-----------------------------------------------------------------------
قابلیت‌ها
-----------------------------------------------------------------------

✅ اسکن شبکه‌های وای‌فای با اطلاعات کامل
✅ گرفتن هندشیک WPA/WPA2
✅ حمله دیکشنری برای پیدا کردن رمز
✅ بازیابی رمز از ویندوز
✅ تنظیمات قابل شخصی‌سازی
✅ تم تاریک و روشن
✅ رابط کاربری زیبا و ساده

-----------------------------------------------------------------------
تکنولوژی‌ها
-----------------------------------------------------------------------

- پایتون 3.8+
- CustomTkinter (رابط کاربری)
- Netsh (دستورات شبکه ویندوز)
- Multithreading (اجرای همزمان)
- JSON (ذخیره تنظیمات)

-----------------------------------------------------------------------
نصب و اجرا
-----------------------------------------------------------------------

1. دریافت کد:
   git clone https://github.com/Nimakoushki/wifi-security-tool.git
   cd wifi-security-tool

2. نصب کتابخانه‌ها:
   pip install customtkinter pyinstaller pillow darkdetect

3. اجرا:
   python main.py

-----------------------------------------------------------------------
چطور کار کند؟
-----------------------------------------------------------------------

اسکن شبکه:
- به تب Scan بروید
- Start Scan را بزنید
- شبکه‌ها را ببینید و انتخاب کنید

گرفتن هندشیک:
- به تب Handshake بروید
- اطلاعات شبکه را وارد کنید
- Start Capture را بزنید

شکستن رمز:
- به تب Crack بروید
- نام شبکه را وارد کنید
- فایل دیکشنری را انتخاب کنید
- Start Attack را بزنید

بازیابی از ویندوز:
- در تب Crack، نام شبکه را وارد کنید
- Find from Windows Memory را بزنید

تنظیمات:
- به تب Settings بروید
- تنظیمات را تغییر دهید
- Save را بزنید

-----------------------------------------------------------------------
ساخت فایل exe
-----------------------------------------------------------------------

1. مسیر customtkinter را پیدا کنید:
   pip show customtkinter

2. این دستور را اجرا کنید:
   python -m PyInstaller --onefile --windowed --add-data "مسیر/customtkinter;customtkinter/" --hidden-import darkdetect --hidden-import packaging --hidden-import packaging.version main.py

3. فایل exe در پوشه dist ساخته می‌شود
